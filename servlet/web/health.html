Servlet health

Live connection-pool statistics from the running servlet container. Refresh a few times: borrows climbs with every request served, while poolSize never moves and reconnects stays at zero. That is the pool being reused rather than rebuilt — the thing a CGI process cannot do.

What each field means

FieldMeaning
status UP once the connection pool has been opened by the startup listener.
poolSize JDBC connections opened once, at application startup, and held open.
idleConnections How many of those are currently back in the pool, not in use.
borrows Total connections handed to a request thread since startup. This is the number that proves reuse.
reconnects Connections replaced after going stale. Should stay at zero.
configSource Which configuration file the running application actually read.
